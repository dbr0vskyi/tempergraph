# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), as its code of conduct. It applies in the repository's issues, pull requests, reviews and discussions, and wherever someone represents the project.

In short: be welcoming, be patient, assume good intent, and criticise work rather than people. Harassment, insults, personal attacks, and publishing someone's private information are not acceptable.

The same standard applies to text that agents post on the project's behalf (CONTRIBUTING.md section 5). The person who runs an agent answers for what it posts.

## Reporting

Report a conduct problem privately to the maintainer, [dbr0vskyi](https://github.com/dbr0vskyi), through the repository's private reporting form ([SECURITY.md](SECURITY.md) says how), with "Conduct" at the start of the title. Reports are kept confidential. The maintainer may remove, edit or reject comments, commits, issues and pull requests that break this code, and may block a contributor who breaks it repeatedly.
