# Triage: i58

## Task

GitHub issue #58: temperspec reads its verification commands from the repository's `tempergraph.commands.json` (engine `@repository` commands) instead of the fixed list, so it runs on repositories that are not Python.

## Acceptance criteria

1. temperspec's steps and checks take their verification commands from the repository's `tempergraph.commands.json` through the engine's `@repository` commands, instead of the fixed list alone.
2. `prepare` writes `tempergraph.commands.json` with today's list when a Python repository has none, and leaves an existing file unchanged.
3. A repository that is not Python and has its own `tempergraph.commands.json` gets its own commands in the plan check and the code gate (offline test with a non-Python fixture).
4. Open question 6 of the temperspec overview spec is removed, and the README's "Limits of this version" line about the fixed list says what is true now.
5. The package's model-free authoring check (`tempergraph author verify plugins/temperspec-tgraph`, rungs that need no model) passes, and the package tests pass through the engine suite.
