# Triage: i126

## Task

GitHub issue #126: temperspec runs each verification command once per session and the code gate reuses the session's own last run (backlog rows B49 and B28; source `plugins/temperspec-tgraph/docs/research/speedup-runs-command-reuse.rsrch.md`).

## Acceptance criteria

1. The code step's prompt tells the session to run each of the plan's verification commands once, after the last phase, and to run only the phase's own tests while working on a phase.
2. The code session's final run of the plan's verification commands goes through the engine's check preview (`tempergraph self-check`), so the gate can reuse it.
3. When the code gate's check runs a plan verification command that the session already ran through the check preview on the same tree content, the gate reuses that result and does not run the command again, even though the engine committed the session's files in between.
4. When any tracked file changed after the session's run, the gate runs the command again.
5. The gate's evidence says for each command whether it was reused or run.
