3. The workflow validates, `blueprint check` and the model-free rungs of `author verify` pass, the package's specs say what the route does now, and the package tests pass through the engine's suite; `ruff check src tests` and `mypy` pass.
4. The live trial run the issue asks for ("a new trial run passes") is a row in the package's live checks with its command and pass criterion; it is not faked, and the orchestrating agent runs it after the merge.
