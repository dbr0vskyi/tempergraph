# Hand-off: i166c

## Problem

The code step has no way to delete files; a plan row that calls for a file deletion causes a `tool_access` pause when the session tries to run a command the step does not declare. Neither the plan check nor the code-step spec stated what a `chore` row is for, what file operations the code session cannot perform, or how such rows should be carried out without calling a model.

## Gaps closed

- G1: `plugins/temperspec-tgraph/docs/specs/plan.spec.md` (PLN-B2) — new behaviour: the plan check fails any non-`chore` row whose Change cell describes deleting a file, moving a file, or writing under `.claude/`
- G2: `plugins/temperspec-tgraph/docs/specs/code.spec.md` (COD-B1) — new behaviour: the code step ensures that a `chore` row describing a file deletion ends with the file absent in the committed result and no run pause raised
- G3: `plugins/temperspec-tgraph/docs/specs/plan.spec.md` (PLN-B1) — existing behaviour extracted: a `chore` row is a valid row kind accepted by the plan check with no preceding test-row requirement

## Uncertainties closed

- U1: Answered: `chore` rows have no model-free execution path today; the code-step prompts (`prompts/code.md:25-30`) give `chore` rows no special instruction and `__init__.py:274-284` declares the step with `after=[_commit()]` and no additional after-script. A new mechanism is designed from scratch. Source: `plugins/temperspec-tgraph/workflow/temperspec/__init__.py` lines 274-284 (read) and `plugins/temperspec-tgraph/workflow/temperspec/specfmt.py:36` (read).
