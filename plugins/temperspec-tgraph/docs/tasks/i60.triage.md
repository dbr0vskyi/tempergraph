# Triage: i60

## Task

GitHub issue #60: temperspec: conversation mode `never` (defaults listed as assumptions in the PR). Add a conversation setting with the value `never` for pipelines and night runs. Triage sorts gaps into findable gaps and owner decisions and takes the default for each owner decision. The pull request lists those defaults as assumptions to confirm. Source: `next-features.rsrch.md` §2 (was backlog row B1, stage S1.4).

## Acceptance criteria

1. The workflow has a conversation setting with the value `never` (other values keep today's behaviour); with `never`, triage sorts each gap into a findable gap or an owner decision, and writes for each owner decision its default answer in the triage note.
2. With `never`, no step or gate pauses to ask a person about an owner decision: the run goes on with the default.
3. With `never`, the draft pull request description lists every default taken as an assumption for the owner to confirm.
4. `prompts/triage.md`, the package's checks and its pull request summary are updated, and the triage judge's seeds still pass the model-free rungs; the package tests pass through the engine's suite.
