# Hand-off: i58

## Problem

temperspec took its verification commands from a fixed Python list, so it ran only on Python repositories. The task makes the steps and checks read the commands from the repository's `tempergraph.commands.json` through the engine's `@repository` commands, makes `prepare` write that file for a Python repository that has none, and brings the overview spec's open questions and the README in line.

## Gaps closed

- G1: RCM-B1 answers it: a command that starts with one the repository declares in `tempergraph.commands.json` is accepted by the triage, plan, expand, code and outcome checks, so a non-Python repository with its own file gets its own commands in the plan check and the code gate (RCM-B4 adds the run in the gate's folder, RCM-B2 the refusal of any other command)
- G2: RCM-B6 answers it: prepare adds `tempergraph.commands.json` with the six Python commands to a Python repository that has none; RCM-B7 leaves an existing file unchanged and RCM-B8 writes none for a repository that is not Python
