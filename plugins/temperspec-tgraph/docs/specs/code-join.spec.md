# code_join

## 1. Overview

The unit both arms of `code_mode` reach after [code](code.spec.md) and the [regeneration](regeneration.spec.md). It receives the run after the regeneration, produces no file, and has no session, gate, check or effect. It is a route: a run of the quick lane goes on from it straight to the outcome gate, and every other run goes on to the [independent review](independent-review.spec.md), which the outcome gate follows. It exists because a switch's join point may not be the entry of an arm. What the two arms run is in [code mode](code-mode.spec.md).

Part of the [overview](overview.spec.md).

## 6. Acceptance criteria

None: a join has no gate criteria.
