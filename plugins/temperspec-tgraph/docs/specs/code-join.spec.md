# code_join

## 1. Overview

The unit both arms of `code_mode` reach after [code](code.spec.md). It receives the run after the code step, produces no file, and has no session, gate, check or effect; it passes the run on to the outcome gate. It exists because a switch's join point may not be the entry of an arm. What the two arms run is in [code mode](code-mode.spec.md).

Part of the [overview](overview.spec.md).

## 6. Acceptance criteria

None: a join has no gate criteria.
