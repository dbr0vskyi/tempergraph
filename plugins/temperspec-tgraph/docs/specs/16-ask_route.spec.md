# ask_route

## 1. Overview

A route with no session. After [owner_questions](15-owner_questions.spec.md), it sends a run whose list holds a question to the [pause](17-ask_owner.spec.md), and every other run on to the reading sessions of the full [discovery](05-discovery.spec.md), so that a run with nothing to ask pauses nowhere.

Part of the [overview](00-overview.spec.md). When a run pauses, and when it does not, are the behaviours OWQ-B1 and OWQ-B2 of [owner questions](owner-questions.spec.md), which this page does not restate.
