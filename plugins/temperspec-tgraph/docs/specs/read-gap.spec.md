# read_gap

## 1. Overview

The findings of the reading of one gap answer the gap, or state what was searched, and name the files they rest on

Part of the [overview](overview.spec.md). The full [discovery](discovery.spec.md) starts with one read-only reading session for each gap of a triage note that lists two or more, three at a time on the engine's concurrent map; its one writing session then closes the gaps from their findings ([parallel reading](parallel-reading.spec.md)).

## 6. Acceptance criteria

- [ ] ts-rdg-cited The findings name each file they rest on with its line ranges or ids
