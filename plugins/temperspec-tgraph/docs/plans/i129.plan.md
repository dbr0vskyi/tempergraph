## 2. Phases

### Phase 1: The engine gives a check the session record

Goal: a check run after a step or retry attempt reads `session` (CHK-B22: the calls of the session since its last start, in order, with name, capability, target and ok, from the attempt's journal, carried through the worker's context document, the attempt record keeping `session_key`) and reads `None` for a stand-in that reports names only, a session with no call, a journal that dropped a tool line and the preview (CHK-B23), proved with engine fixtures that name no workflow in a new test file that also proves CHK-AC17 and CHK-AC3.
Weight: heavy (many-tests)

### Phase 2: A step opens the rule file its prompt names

Goal: the check of each of the seven steps fails naming a rule file that its prompt names, the repository holds and the session record shows no opening of, and does not apply where the repository holds none or the record is absent, and the seven prompts tell the session to open each rule file with the read tool; `outcome.json` is at revision 13 with the seven rule-file criteria, and the package's helpers for reading the record are in place.
Weight: heavy (many-tests)

### Phase 3: The expand step opens each file a row names

Goal: the expand prompt tells the session to open each file a row names before it writes the row, and the expand check fails naming the row and the path for a row whose existing file the record shows unread (a file that does not exist, a `docs` row's spec, two rows of one file), with `ts-exp-opened` in `outcome.json`.
Weight: light

### Phase 4: The code step writes each phase's tests before its source

Goal: the code check fails naming the phase when the record shows a `code` row's file of the phase changed before the first write of a `test` row's file of that phase, with the first-phase ownership of a shared file, no failure for a `docs` or `chore` row, for a phase whose test files are never written or for a call that ended with an error, the quick lane not applicable, and `ts-code-order` in `outcome.json`.
Weight: light
