## 2. Phases

### Phase 1: The setting and the note's shape

Goal: with `--set settings.conversation=never` a run holds the value `never`, `always` is refused before any spend, the triage prompt asks for the sort and the owner decisions only under `never`, and the task-notes rule and the format module describe and read the same sort and `Owner decisions` entries.
Weight: medium

### Phase 2: The triage check refuses an incomplete sort

Goal: under `never` the triage check fails `ts-tri-owner` on every incomplete note, `outcome.json` holds the criterion with the text of its row in `04-triage.spec.md`, and the triage judge's met seeds and a note with no sort still pass when the value is `blocking` or not given.
Weight: light

### Phase 3: Discovery goes on with the default

Goal: the discovery prompt makes `never` end no step blocked on an owner decision while `blocking` keeps ending blocked, and a package test shows that no unit asks a person, no gate requires a sign-off, and every judge brief after triage leaves an open question ungraded.
Weight: light

### Phase 4: The description lists the assumptions, and the documents follow

Goal: the pull request description built from a triage note lists each owner decision under `Assumptions to confirm`, and the README and the research note's status line say what is built.
Weight: light
