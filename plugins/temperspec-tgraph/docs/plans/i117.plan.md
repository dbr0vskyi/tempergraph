## 2. Phases

### Phase 1: The setting, the note's shape and the triage check

Goal: with `--set settings.conversation=never` a run holds the value `never`, the triage prompt and rule ask for the sort and the owner decisions, the format module reads them, and the triage check fails `ts-tri-owner` on every incomplete note and passes the triage judge's met seeds.
Weight: medium

### Phase 2: Discovery goes on with the default

Goal: the discovery prompt and the task-notes rule's hand-off bullet make `never` end no step blocked on an owner decision while `blocking` keeps ending blocked, and a package test shows that no unit asks a person and that every judge brief after triage leaves an open question ungraded.
Weight: light

### Phase 3: The description lists the assumptions, and the documents follow

Goal: the pull request description built from a triage note lists each owner decision under `Assumptions to confirm`, the README and the research note's status line say what is built, and the package's model-free authoring check has run on the changed prompts and `outcome.json`.
Weight: light
