The out-of-scope list of the task (a cause code, a cap across invocations, `resume --decision retry` on an unfinished thread, the scheduler's reading of exit 4) is left alone.
- Existing tests that use the cap to leave a thread unfinished and so pin the old count: `plugins/tempergraph/engine/tests/test_run.py` (the CMP-AC8 test, lines 180-191), `plugins/tempergraph/engine/tests/test_map.py` (the MAP-B4 test, lines 157-165) and `plugins/tempergraph/engine/tests/test_feedback.py` (lines 109-121).
