## 2. Phases

### Phase 1: A CLI without the MCP isolation flag is refused

Goal: the `claude` probe fails with reason `probe_failed` and a message naming `--strict-mcp-config` when `--help` does not list it, and passes when it does; the stand-in `claude` lists the flag by default so that every offline probe of it keeps passing.
Weight: light

### Phase 2: Declared servers the operator does not define are refused at preflight

Goal: preflight refuses a step, map or contest unit that declares an MCP server the operator's own configuration does not define, naming the unit and each server, and passes it once every declared server is defined; the claude executor answers through an optional method, and the stand-in executors are unaffected.
Weight: medium

### Phase 3: A launch never drops a declared server

Goal: a step or retry launch whose declared server is undefined at launch, or that has no scratch folder, starts no session and fails with a reason naming each server, and the private config lists every declared server; the three tests that pinned the silent strict launch and the dropped server change with the rule.
Weight: medium

### Phase 4: The live probe reads every turn

Goal: a helper, importable offline, reads the tools or the context size of each turn of a session of more than one turn and reports a turn that shows an undeclared server's tools or a context of more than 30,000 tokens (the operator measured about 9,000 at every turn when isolated and 174,123 at the second turn when not); the live test for P-CC-13 runs a step and a judge for more than one turn through it, with the launch as the engine builds it, and a control launch without `--strict-mcp-config` and the environment variable that the helper flags; offline tests of the helper carry ECC-AC19.
Weight: medium

### Phase 5: The record says what was run and agrees with what was confirmed

Goal: the runbook's L-43 rows say what the operator ran by hand on 2026-11-25 with its figures and mark the pytest test as not run, and the compatibility record lists the confirmed version in `recorded` and inside `range`, with the tests that read both changed to match.
Weight: light
