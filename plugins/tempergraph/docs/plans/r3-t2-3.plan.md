- Files opened beyond the hand-off's reading list, for the gate's reason only: `plugins/tempergraph/engine/tests/test_upgrade.py` (full read, it is on the list for its fixtures) to find which tests prove the scenarios of WUP-B8, WUP-B17 and WUP-B18; `tests/test_upgrade_workflow.py` (head and test names) for the assisted edit, the owner pause and the judge of WUP-B3 and WUP-B4; `tests/test_audit.py` (lines 540 to 550) for the re-approval test of WUP-B13; `tests/test_stamp.py` (lines 20 to 50) for the `cli` and `caps` helpers; `tests/test_subworkflow_upgrade.py` (the built test of scenario 6); `src/tempergraph/cli/upgrade.py` (a search) for how `upgrade-check` is wired; a search of `tests/` for `WUP-` to list the criterion ids tests carry today.
- Why this design: spec 99 already states every behaviour, so the plan adds none. A child runs under a spec renamed to the parent (`subrun.applied` sets `name=parent.name`), so every lookup keyed by `spec.name` (judge binding and grade, causes, finding lines, filing, measures) reads the parent inside a child. Each phase finds the lookup that serves one result and makes it read the child, with an engine fixture parent and child and stand-in executors, never a shipped workflow (ADR-0129). The plan is `complex`: more than 3 phases and more than 6 test rows and 10 files are expected.
- Choices left to the plan by the hand-off: (1) the child's `changes/<version>.json` follows VER-B9's entry shape narrowed by VER-B17 and is read by `package/changelog.py` for each sub-workflow unit of the parent, from the child's registered package, between the version the parent was last stamped against and the child's current version; (2) its detect rule for a parent's reference to a produced key is `template_key` on `<unit>.<key>`, with the `rename_field` item pointing at that reference (the item needs an action that renames a produced key in the parent's templates, since the shipped `rename_field` renames a builder keyword); (3) no promotion window counts a child's records from inside a parent in this release (ADR-0133 assumption A2). The hand-off's open question about how a window could say so stays with the owner and blocks nothing.
