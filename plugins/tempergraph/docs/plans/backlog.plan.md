# Backlog of the engine

The one list of engine features found useful and not built yet, and not yet given a place in a release plan. A feature enters here when the owner says it is worth having, and leaves when it is built or moved into a release plan: its row is deleted in that pull request, so the list never holds history. The reasoning behind each row is in the note its Source column names. Like every engine plan, no row names a workflow package ([ADR-0129](../adr/0129-the-engine-names-no-workflow-and-takes-requests-as-general-capabilities.adr.md)); a workflow's own wants are in that workflow's backlog.

**How to use it.** To build a row: read its source, state the behaviour in the owning spec, build it, and delete the row. To add a row: one line, with its source.
