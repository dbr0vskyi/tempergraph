## 2. Phases

### Phase 1: Declaration

Goal: a concurrent map validates (R1): the refusal `not_in_release` of `mode` is replaced by the check of `concurrency` from 1 to 10 and by the finding for a writing concurrent map in an `in_place` workflow, `flow.py` gains the test that says whether a map's step is a writer, and the map unit's docstring that calls the mode a later release is corrected.
Weight: light

### Phase 2: Items at once, each with its own state

Goal: a concurrent map runs up to `concurrency` read-only items at once, each item through the unit's four nodes with its own attempt, judgement, feedback, counters and route, a read-only item that changes the run worktree failing, and a sequential map behaving exactly as before (R2, R3).
Weight: heavy (refactor)

### Phase 3: Writing items in their own worktrees

Goal: a writing concurrent map commits a checkpoint when it is entered, runs each item in its own sibling worktree, and at the end of the map merges the items without fast-forward in list order, a conflict resetting the run branch and blocking the map with the paths and no model session, by reusing `workspace.cut_writers`, the checkpoint commit of `fork` and `_merge_writers` of R3-T3.1 (R4, R5).
Weight: medium

### Phase 4: Item pauses and resume by item

Goal: a spent item of a concurrent map pauses with kind `budget` addressed by unit and item while the others keep their results and start no session after a resume, a resume without an item is refused with every exact command, and a named item's `retry` or `stop` acts on that item only (R7).
Weight: medium

### Phase 5: Reservations and the check after the merge

Goal: concurrent items take reservations from the ledger under the run cost cap, and a writing concurrent map's gate check runs once on the run's worktree after the merge and before the next unit, a failure ending the map blocked and not retried (R6, R8).
Weight: medium

### Phase 6: Documents

Goal: every document the change makes false says what is built: spec 08's and spec 82's "Not built yet" bullets, the rationale note's "As built" bullet, the release 3 plan's status and R3-T3.2 phase, the docstrings that name the sequential-only map, and the test that pins the words of spec 08's bullet (R9).
Weight: light
