- Open question taken at its default (hand-off Option A): the builder reads each `inputs` value into `request`, `<unit>.<key>` or a quoted literal, and a value of any other form fails when the declaration is built; validation adds no refusal beyond SWF-B6's list.
- Order of the interim stop in the run path (hand-off): after validation findings, settings, executor preflight, `needs_git` and the carry check, before `ensure_state_root`.

## 2. Phases

### Phase 1: The declaration

Goal: `Subworkflow(...)` builds a unit record that holds every field of SWF-B7, `validate` no longer refuses the kind as `not_in_release`, and the template grammar parses `{<unit>.<key>}`, with the tests that pinned the old placeholder and the old grammar changed.
Weight: medium

### Phase 2: Validation refuses every bad child

Goal: one registry reader resolves a child, and `validate` refuses each SWF-B6 case it can see (recursive, depth, input-missing, version, unknown, produces, builtin) and accepts `{<unit>.<key>}` for an exposed key, each with an offline fixture test carrying SWF-AC1 or SWF-AC5, and a valid parent with a child passes.
Weight: heavy (many-tests)

### Phase 3: The start

Goal: a start outside git is refused `needs_git` for a child that needs git, a run and `run --check` of a valid parent stop with the one SWF-B11 message before any spend, and `blueprint check` still refuses `subworkflow`.
Weight: medium

### Phase 4: Documents and the gate

Goal: the spec's "Not built yet" line and the release 3 plan's R3-T2.1 status say what is built, and the engine's offline suite, `ruff check src tests` and `mypy` pass.
Weight: light
