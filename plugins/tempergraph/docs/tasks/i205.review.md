# Review: i205

## Findings

1. `plugins/tempergraph/engine/src/tempergraph/run/subrun.py:144` not blocking: the child context is built with `dataclasses.replace`, so its `counted`, `started` and `trips` dicts are the parent's own dicts, keyed by bare unit name. A child unit and a parent unit with the same name share one entry. The `repeated` list of the exit at the cap (CMP-B20) can then show merged `attempts` and `trips_back` for them, and it cannot tell a child unit from a parent unit. Only the report is wrong. The cap check itself is not affected.
2. `plugins/tempergraph/engine/src/tempergraph/run/nodes.py:663` not blocking: a session that ended `partial` and not `ok` is turned into `Drain` whenever any stop request is pending. This holds for a `drain` request too, and for a session that ended partial for another reason, such as a kill after a timeout. That attempt then records nothing and spends no retry or infra try. RCT-B11 speaks only of a `now` stop, and no test covers a drain request that arrives with an unrelated partial result.
3. `plugins/tempergraph/docs/specs/compiler-and-flow.spec.md:114` not blocking: the CMP-B19 scenario describes a workflow's shape ("thirty units, among them a council, a sub-workflow and a map of twenty items"). `spec.rule.md` asks for placeholders and no description of a workflow's units. Otherwise the specs name no workflow.
4. `plugins/tempergraph/engine/tests/test_spec_budget.py:7` not blocking: `CHANGED_SPECS` lists `map-unit`, but this change does not touch `map-unit.spec.md`. The new test's comment cites "AC 10" and ids of changed specs only, so the list does not match what the change edited.
5. `plugins/tempergraph/engine/tests/test_map.py:164` not blocking: criterion 4 allows the existing cap tests to change only in the number they set. `test_a_drained_run_resumes_at_the_pending_item` now uses a different fixture (`p1_fails_once`) and different judge and step scripts. The MAP-B4 behaviour (resume at the pending item, passed items not rerun) is still checked, but the test is no longer the same test.
