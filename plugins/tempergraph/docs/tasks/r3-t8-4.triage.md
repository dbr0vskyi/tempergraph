2. 3. FLX-B8 and the ask spec state the new value with a GIVEN/WHEN/THEN example and a new acceptance criterion id, tests carry that id, and the release 3 plan row I3-15 drops "(if the owner agrees)" and records it as built.
4. The engine's offline suite (`python -m pytest`), `ruff check src tests` and `mypy --python-version 3.13` pass.
