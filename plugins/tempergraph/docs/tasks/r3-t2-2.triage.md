# Triage: r3-t2-2

## Task

Engine release 3 plan, track R3-T2, phase R3-T2.2 "Running a child" (`plugins/tempergraph/docs/plans/third-release.plan.md`): a parent run runs its sub-workflow child as one unit, replacing the `not_in_release` refusal of phase R3-T2.1. Measures and carrying (SWF-B9, SWF-AC3) are out of scope.

## Acceptance criteria

1. A parent run that reaches a sub-workflow unit runs the child's units in the parent's workspace and thread, its records in the parent's `run.jsonl` each carrying `child: <unit>`, session keys `<unit>/<child unit>.<attempt>.<kind>`; the child's outcome gate grades its final criteria, the parent's gate for the unit grades what `produces` exposes, and a later parent unit reads `{<unit>.<key>}` (SWF-B1, SWF-B8).
2. A run with a child leaves one `run.jsonl`, one checkpoint thread and one ledger row (SWF-AC2), and the child's `workflow_version` is recorded in `run_started.children`.
3. A child pause pauses the parent with `unit` reading `<unit>/<child unit>`, `status` shows it, and `resume … --decision proceed` releases it with no parent unit after the sub-workflow having started (SWF-B2); a parent paused inside a child whose version changed resumes with one `workflow_changed` record naming `child: <unit>` (SWF-B3).
4. A child attempt that would start at or over the parent's run cost cap drains the run with exit 5 `cost_cap`; the child's spend counts against the parent's caps and is shown on its own line in reports (SWF-B4).
5. A child judge's upstream defect in a key the parent mapped into `inputs` sends the parent back to the unit that made that key when it is a back target, else asks a person; a child outcome of `unmet` or `needs_person` fails the unit's gate with the child's failing criteria as blockers (SWF-B5). The child's finalizer never runs from the parent and its outcome gate is never skipped (SWF-B10).
6. Offline tests on stand-ins with engine fixture workflows prove 1 to 5 and carry SWF-AC1 or SWF-AC2; SWF-B11 and SWF-AC4 are removed from spec `subworkflow-unit` with the refusal they describe; the "Not built yet" line names only measures and carrying; the release 3 plan records R3-T2.2 as built; the offline suite, `ruff check src tests` and `mypy` pass.
