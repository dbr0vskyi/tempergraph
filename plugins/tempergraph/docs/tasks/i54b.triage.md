# Triage: i54b

## Task

GitHub issue #54 (was backlog row B20, source R-160, run r3-t1-1b): the temperspec code check treats a failure already present before the change as a retry. It should run the verification commands, compare them with the run's base, and escalate as environmental a failure that was present before the change or that no changed file touches.

## Acceptance criteria

1. When a verification command the plan lists fails at the code gate and the same command also fails at the run's base commit, the code check returns an environmental result: the gate escalates with no retry and no judge.
2. When a verification command fails and none of the run's changed files is touched by that failure (no changed path appears in the failure's output and the command's failure is the same at the base), the check returns environmental, not a retry.
3. A verification command that passes at the base and fails on the branch head still fails the check as today, so the code step retries.
4. The check's evidence names each command, its exit at the base and at the head, and why it was judged environmental.
5. The base result is computed at most once per command per gate visit (no extra spend on a passing command).
