## Decisions

- None: the triage note lists no owner decision.
- What the cap counts: an attempt counts only when its unit, item or slot has made an attempt earlier in the thread (a retry, or a visit begun by a trip back or a rewind); a first attempt never counts. Stated by the task (criterion 1's first example); the other example, a map's items counted once, would still stop a run with many units.
- Once the count reaches the cap, the run stops before the next attempt of any kind, as the code does at `run/nodes.py:290`; only the rule for what raises the count changes. Chosen as the least change.
- A trip back over more units or items than the cap stops the invocation at the cap; a plain `resume` continues it with a fresh count (the consequence of counting a visit after a trip back, as the task's example does).
