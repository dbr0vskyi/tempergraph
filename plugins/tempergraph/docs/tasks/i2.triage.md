# Triage: i2

## Task

GitHub issue #2: start the improvement loop also on runs that end without a final exit (a thread stopped or marked unfinished while paused, a runner that was killed or timed out). The loop should find these at the next `status`, `stop` or `attention`. Motivation: research `does-the-improvement-loop-find-what-a-reviewer-finds` F7 (four of eleven overnight runs had no loop). Was engine backlog row E1.

## Acceptance criteria

1. SIL states the new start triggers. Each trigger starts the loop once per thread.
2. A run that is paused and then stopped gets its friction lens and its session review.
3. A killed runner found by `status` gets its loop, and it is never started twice.

## Existing documents

- `plugins/tempergraph/docs/specs/self-improvement.spec.md`: SIL-B1 starts the loop only at a final exit; SIL-B9 treats only exits 0, 4 and 5 as final and says a pause (exit 3) runs no lens of a final exit; SIL-B8 records on every exit; SIL-B10 lenses run on final exits. It has no trigger for a stop while paused, a killed runner or a timeout, and no once-per-thread rule. It holds no "Not built yet" line for this issue.
