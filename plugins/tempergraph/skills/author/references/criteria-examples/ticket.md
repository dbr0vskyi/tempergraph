# Criteria examples: a ticket

| Criterion | Class | Scale or verifier |
|---|---|---|
| The ticket has a title, a description and acceptance criteria | `check` | `headings_in_order` or `pattern_present` per part |
| Every acceptance criterion is a testable statement | `judge` | met: each names an observable result; partial: one is vague; unmet: most are vague; evidence: the criteria |
| The reproduction steps lead to the reported symptom | `judge` | met: following the steps shows the symptom as described; unmet: they do not; evidence: the steps and the symptom |
| The priority matches the team's rules | `check` | `value_in_choices` on the reported priority |
