# Criteria examples: a message

| Criterion | Class | Scale or verifier |
|---|---|---|
| Every action item names one owner | `check` | `pattern_absent` for an action line with no owner, once the format is fixed |
| The message is at most 200 words | `check` | a hand-written check that counts words |
| The first sentence says what the reader must do | `judge` | met: the first sentence names an action and a deadline; partial: an action but no deadline; unmet: no action; evidence: the first sentence |
| The tone fits the audience | `person` | role: the sender; question: "Would you send this as it is?" |
