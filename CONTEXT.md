# Context for Claude / contributors

tempergraph is an opinionated, LangGraph-based Python workflow framework.

What it should do:
- Enforce AI engineering practices so less experienced users can build good workflows.
- Help the user define what a good outcome is.
- Enforce deterministic checks and LLM-as-judge checks.
- Support graph-based loopbacks and returns driven by those checks.
- Include self-improvement and other batteries-included features.

Repo: private, github.com/dbr0vskyi/tempergraph (origin), main branch; design documents only, no code yet.
Tagline idea: "Tempered rails for AI workflows".
