# Hand-off: i170b

## Problem

The friction judge is told wrong or empty facts about a pause. A finding is told another segment's pause or a row of six `not recorded`, a run's own commits read as a change of the workspace, the next gate is taken from another item, a ruling reads as no feedback, the brief and the prompt say nothing of the paused segments, an issue for a pause finding is built from the last segment, an agent's decision at a run it supervises is filed as a workflow fault, and the final exits 4 and 5 have no criterion and no guide line for earlier pauses. The specs now state each rule for any workflow: the pause a finding is told, the facts told, what a resume compares, the brief's sentences, a section for each segment, the segment an issue is built from, the class of the starting caller's decision and the final exits that carry earlier pauses.
