## Deviations

1. **Test-first order was not kept for phase 1 and for rows 2.5 and 2.6.** I wrote the phase 1 code (`params.py`, `child.py`) right after its tests without running them red first. I also wrote `record.py` (rows 2.5, 2.6) before the phase 2 tests. The phase 2 breakpoint-stop test (row 2.1) and all phase 3 lost-runner tests did fail first, for the right reason (no ledger row, no `runner_lost` row). The gate-stop tests of `test_stop_at_pause.py` passed on the first run because `record.py` was already changed; I did not reproduce them red.
2. **`lost.settle` has an extra optional argument `registry`.** The plan names `settle(root, specs, selector=None)`. The registry is only used for `TEMPERGRAPH_LOOP=inline`. `cmd_status`, `cmd_stop` and `cmd_attention` pass `env.registry`.
3. **`cmd_status --all-roots` settles only the current root.** `cmd_status` passes `[_root(env)]`, as the plan says ("for the root"). The other roots listed by `--all-roots` are shown but not settled. `cmd_attention` settles every root it reads, as the plan says.
4. **Lost segment's ledger row.** It has no `supervision` or `outcome` key and `grants: []`, since the process that held that state is gone. `operator_review`, `daily_cap_usd`, `loop_model` and `loop_effort` are not known for a lost segment, so its ticket takes the defaults. The judge executors come from the segment's `run_started` record.
5. **Stable-mode test (row 2.3) uses a first segment with `retry_budget` 0.** With the default budget the judge-blocked finding makes the plan target every attempt, so the targets would be more than "the last attempt and the judge". With one attempt, the targets are exactly `draft.1.step` and `draft.1.judge`. The test asserts that set, and that `retries_spent` is among the target reasons. The step in that fixture reports a `Read` tool call so its digest has a turn to read.
6. **Row 3.1 fixture.** `test_orphaned_thread`'s fixture has no failed check, so `test_lost_runner.py` uses a check that fails on the first attempt and a judge that raises on the second. That gives the `check_fail:draft` finding SIL-AC20 names.
7. **`unjudged_pause_findings` compares times as parsed datetimes.** `findings.json` times end in `+00:00` and loop-log times in `Z` with milliseconds.
