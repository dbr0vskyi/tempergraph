# Hand-off: i21

## Problem

A `claude` step session is offered the account's claude.ai connectors (about 165,000 tokens of tool definitions from the second turn) because the executor sends `--strict-mcp-config` only under enforcement with an MCP tool declared. A judge's ordinary launch sends `--disallowedTools "mcp__*"` and no `--strict-mcp-config`, and no launch switches the connector fetch off. The spec `executor-claude-code` now states, as rules of the launch, the strict MCP flag on every step, retry and judge launch, the step's own private config of its declared servers, and `ENABLE_CLAUDEAI_MCP_SERVERS=false` in every session's environment.
