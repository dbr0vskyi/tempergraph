# Triage: i206

## Task

`batch-queue/tasks/i206.md` (GitHub issue #206, first slice): the independent reader is given the whole change of the run. The task gives a script unit the run's base commit and builds the reader's inputs from it. It adds guards against an empty or short input, a file list beside the diff, and spec and brief changes.

## Acceptance criteria

1. A script unit is given the run's base commit, the same value a check of the same visit reads as its base. The engine spec states it without naming a workflow, and an engine fixture run proves a script and a check of one run read the same commit.
2. The reader's inputs are built from the base the engine gives, not from commit subjects. A package test with a commit made by hand between two run commits proves the diff holds the files of every run commit.
3. `review_check` fails `ts-rev-form` when the base the inputs were built from differs from the base the check is given, with a finding that names both commits.
4. `review_check` fails `ts-rev-form` when the diff given to the reader is empty while the run changed at least one path, with a finding that says the reader was given no change.
5. A git command that fails or times out while the inputs are built fails the attempt with a finding that names the command; no empty input is written in its place. A test proves each of the two cases with a replaced `git`.
6. A file list stands beside the diff: one row per changed file with its added and removed line counts, files a declared regeneration writes (stamps, diagrams) listed last and marked as generated.
7. The reader's brief names the file list, tells the reader to open it first, and tells it to read a large diff in pages; a test asserts the three sentences.
8. `independent-review.spec.md` states the behaviours of criteria 2 to 7 and its criteria list carries them; the package's own note of the engine need is written before the engine change, as the ADR asks.
9. The criteria above are numbered 1 to 9 with no gap and are the whole slice. Each new test carries the id of the spec criterion it proves, no test writes by hand a record in a shape the engine never writes, and the package's existing review tests still pass, changed only where a criterion above changes the fact they assert.

## Intent

- Goal: the independent review gate can no longer pass because its reader was given a cut-short or empty change. The reader sees the full change of the run, and the gate fails loudly when it does not.
- In scope:
  - The engine gives a script unit the run's base commit, as a general capability.
  - The reader's inputs use that base.
  - Three failure guards: a base mismatch, an empty diff, and a failing or timed-out git command.
  - A file list beside the diff, and three brief sentences about it.
  - The spec behaviours and criteria for these, and the package's note of the engine need.
- Out of scope (each named in the report):
  - Enforcing what the reader may read (i206b).
  - The brief's new questions, the task statement for the reader and the model-free backstop (i206c).
  - A setting that turns the unit off (i206d).
  - How the improvement loop reads a blocking review (i206e).
  - The live cost and wall-time run.
  - Moving `regeneration.py` to the engine's base. It changes only where criterion 2 makes its test false.
- Assumptions:
  - A1: "the same value a check reads as its base" means `git.base` of the check context (`GitFacts.base`, `run/checks.py`). If wrong: the engine field and spec wording change.
  - A2: A run in place, or a repository with no git, gives an empty base to a script, as a check gets today. If wrong: the empty-base behaviour of criterion 1 is rewritten.
  - A3: The reader's brief is the prompt `prompts/independent_review.md`. If wrong: the brief test of criterion 7 targets another file.
  - A4: The new package behaviours extend IRV-B3 or take new ids in `independent-review.spec.md`. Existing ids are not renumbered. If wrong: the spec layout changes.
  - A5: The root `docs/tasks/` is the notes folder, as the other i-numbered notes show. If wrong: the note is moved.
