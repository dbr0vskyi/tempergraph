# Triage: i144

## Task

`batch-queue/tasks/i144.md` (GitHub issue #144): workflow package tests started from the package's own folder write the real machine index and stats. The engine isolates the home folder and turns the improvement loop off only inside its own suite (`plugins/tempergraph/engine/tests/conftest.py`, autouse fixture). The task asks for that isolation for any test that imports the engine, and for a verb that removes dead state roots from the machine index and their rows from the month's stats.

## Acceptance criteria

1. A test that imports the engine and starts from any folder (a package's own folder included) runs with a home folder of its own and with the improvement loop off, with no fixture written in the package.
2. A test of the engine's suite starts a fixture package's tests from that package's folder and shows that no file of the real home folder and no entry of the real machine index changed.
3. A verb removes from the machine index every state root whose folder no longer exists, and from the month's stats the rows of those roots, printing what it removed; with `--check` it prints the same and changes nothing.
4. The engine's specs state both (the isolation and the verb) without naming a workflow.
