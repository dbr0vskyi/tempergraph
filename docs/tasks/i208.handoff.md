# Hand-off: i208

## Problem

The loop files by default, and a dry run becomes an ordinary run setting, `loop_dry_run`, that a workflow declares, a settings file or a profile sets and `--dry-run` or `--no-dry-run` overrides on `run` and `resume`; `--no-dry-run` also lifts a declared autonomy `record` to `file` for one thread, under the machine's hold. The loop's summary and `status` then say whether an exit filed, ran dry or was held, and which input decided it. No spec stated the setting, the second option, the order of the inputs or the two words, so one new spec owns them and eleven specs change where one of their rules changed.
