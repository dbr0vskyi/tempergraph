# Review: i201

## Findings

1. `plugins/tempergraph/engine/src/tempergraph/run/nodes.py:1682` blocking: `_declared_files` looks up the `produces` key as it is (`key not in values`), but a map unit stores its artifacts per item as `key[item]` (`run/mapping.py:116`) and holds the plain key only once the map has joined, and then only for the last item (`nodes.py:1095-1099`). The judge of a map item therefore never leaves that map's declared file artifacts out of `changed_total` and `changed_read`. This is a wrong count for a declared file artifact, which SRV-B41 and criterion 1 say no judge counts. No test covers a map unit with a file artifact.
2. `plugins/tempergraph/engine/src/tempergraph/run/nodes.py:88` not blocking: `fnmatch.fnmatchcase` also treats `?` and `[...]` as wildcards, but SRV-B42 names only `*` and `**`. A pattern with a bracket, or one with a trailing `/` (`posixpath.normpath` drops it, so `dist/` matches nothing), skips different paths than the spec describes.
3. `plugins/tempergraph/engine/src/tempergraph/run/nodes.py:1699` not blocking: any exception from `base_problem` (for example a git timeout) is recorded as `outside_repository`. That reason is wrong for a workspace inside a repository.
