## Problem

The task adds a unit with no session after the code step that runs the commands a repository declares for its generated files when their inputs changed, commits what they wrote, and sends a failure back to the code step once as numbered findings, with two engine needs beside it: `author verify` in a linked worktree, and a gate with no judge that sends the run back with findings.
