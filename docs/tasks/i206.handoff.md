# Hand-off: i206

## Problem

The independent reader's change is built from the run's commit subjects, and the git calls that build it return an empty text when they fail, so a commit made by hand can cut the change short and a failing or timed-out git leaves the reader an empty change that the gate passes. The task gives a script the run's base commit as a general engine capability, builds the reader's inputs from it, adds guards for a base that differs, an empty change, a run with no base commit and a failing git, gives the reader a file list with the generated files last, and adds three sentences to the reader's brief. Discovery wrote one engine behaviour and nine package behaviours with their criteria; the engine change, the package change, the brief and the tests are the plan's.
