# Hand-off: i144

## Problem

The engine isolates the home folder and turns the self-improvement loop off only for its own suite, through an autouse fixture in `plugins/tempergraph/engine/tests/conftest.py`. Tests of any other package that import the engine, started from their own folder, get no such fixture and write the real machine index and stats. Nothing removes an index entry or a stats row of a state root whose folder is gone, and CST-B8 said readers never remove one. TST-B7 and TST-B8 now state the isolation for any test that imports the engine, wherever pytest starts, and CST-B17 to CST-B21 state `stats forget`, the verb that removes gone state roots and their rows. Neither names a workflow.

## Decisions

- Owner decisions of the triage note: none listed, so none answered and none defaulted. The prompt's conversation value and the owner's answers arrived as unfilled placeholders, so no pause is assumed and each open question below carries `Until answered`.
- The verb is `stats forget [--check]`, a third action beside `stats flush` and `stats sync`. The triage names `central-run-stats.spec.md` as owner; CLI-B7 lists the top-level verbs exactly, so a new top-level verb would change it; `store` verbs are owned by `local-observability-store.spec.md`; and `stats prune` would sit badly beside LOS-B16, which says retention never prunes stats. LOS-B16 is scoped to `store prune`'s retention rule, so it is not contradicted and not edited.
- "The month's stats" of task criterion 3 is read as the stats of the month in which the verb runs, in UTC (the month of a row's `ended_at`). Earlier months are left as they are. See the first open question.
- A removed root's rows are only local stats rows: the delivered rows in a sink and in the fleet copy carry no `state_root`, are another machine's shared files (one writer per file, CST-B13) and are left alone, as is the outbox.
- `--check` takes no lock and the real run takes the index lock; a held lock refuses with exit 2 (preflight refusal with nothing changed, CON-B13).
- `CLI-B14` lists the owners of `stats` by id and `CLI-B7` lists the top-level verbs. Both stay true, so neither is edited.

## Open questions

- Which months does `stats forget` clean? Options: a) only the month in which it runs; b) that month, or the month named by `--month YYYY-MM`, an option `stats` already takes; c) every month's stats file. Until answered: a (it removes the fewest rows and nothing it removes can be restored). If b: CST-B18 and CST-AC8 take the month from `--month`, default the month in which it runs. If c: CST-B18 drops the month clause, its third scenario and CST-AC8.
- The engine's own fixture also clears `TEMPERGRAPH_STATE_ROOT`, `TEMPERGRAPH_CALLER`, `TEMPERGRAPH_CALLER_APP`, `TEMPERGRAPH_SUPERVISOR_TOKEN` and `TEMPERGRAPH_SESSION_KEY`. A package's tests run by a coding session of a run inherit the session's values. The task names only the home folder and the loop. Options: a) the specs stay as the task says; b) TST-B7 and TST-B8 gain a behaviour for those variables. Until answered: a.
