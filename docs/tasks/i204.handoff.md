# Hand-off: i204

## Problem

A judge that has the read tools sometimes ends its judgement by saying what it did not open: it grades a blocker PARTIAL or UNVERIFIABLE and sets `gap`, and today a gap pauses the run for a person and a PARTIAL blocker retries a step that cannot fix it. The engine gets a mark for such a grade and one bounded re-read by the same judge before any verdict is derived (`judge-and-verdict`, with the kind and field lists of the specs that own them), and every judge brief of the temperspec package tells its judge to open a row's file before grading and to mark a grade that fails only for want of a reading (`judge-reading`).
