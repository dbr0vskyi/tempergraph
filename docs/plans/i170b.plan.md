## 2. Phases

### Phase 1: What a resume compares

Goal: a segment that ends with its worktree to be resumed writes the head and the sorted status lines of the worktree beside the run log; the resume reads and removes that marker and `attach_workspace` records `reused` unless the head or the status differs from it, counting the commits since the marked head and the status lines that differ; with no marker it compares as it does today; a run in place writes none. Files: `workspace.py` (marker functions and an optional keyword-only parameter of `attach_workspace`), `run/runner.py` (the write after the segment settles, the read before the attach), tests `test_workspace.py` and the fixture of SIL-AC46 and WTR-AC15 in `test_pause_findings_at_final_exit.py`.
Weight: medium

### Phase 2: The facts of the pause's own segment

Goal: finding lines carry `segment_started`; `pause_facts` finds each finding's segment from it (with the exit time of the segment as the fallback for lines without it), picks the pause by SIL-B39, names its unit and item in the row, takes the next gate by unit, child and item, reads the ruling and the touch classes from the decision row, and leaves out a finding that has no pause, decision or gate. Files: `improve/record.py` (the new field in the finding line), `improve/pause_facts.py`, tests for AC 1, AC 3 and AC 4 including the ruling canary of SIL-AC44.
Weight: medium

### Phase 3: The brief and the sections of the prompt

Goal: the brief of `improve/child.py` holds the three sentences of SIL-B44 beside the sentence of FFD-B6; the row on what answered a pause names the unit and item, the ruling and the touch class; the prompt shows the section of the last segment and one section for each earlier paused segment that holds a listed finding, headed by exit code and reason, built from that segment's own records and holding no text. Files: `improve/child.py` and its tests for AC 5 and AC 6; `test_loop_child.py` keeps passing.
Weight: medium

### Phase 4: The issue built from the paused segment

Goal: the context of an issue or comment (`improve/issue_context.py`, `improve/filing.py`) is built from the segment of the first finding listed under `## Evidence`, with the start, exit code 3 and reason of a paused segment under `## Run`, that segment's records of the finding's unit under `## Run log` and the facts of Phase 2 under `## Run`; a finding of the last segment gives the output it gives today. Files: `improve/issue_context.py`, `improve/filing.py`, `improve/child.py` (the facts passed into the candidate's context), tests read the body the memory code host received.
Weight: medium

### Phase 5: The starting caller's decision is designed

Goal: `derive` gives a finding `agent_decided:<pause cause>` the class `designed` when the decision's caller has the same `host` and recorded `host_session` as the first `run_started` of the thread, and `fault` otherwise; `record_exit` passes that caller and writes the class of the line; a `designed` line is recorded, never judged, never filed. Files: `improve/causes.py`, `improve/record.py`, tests for the three cases of FRC-AC6 in `test_friction_causes.py`.
Weight: light

### Phase 6: Final exits with earlier pauses, and the spec set

Goal: one parametrised test proves that exit 4 with `stopped_by_request`, exit 4 with `attempt_cap` and exit 5 carry the earlier pause's fingerprint under `pause_fingerprints` (no behaviour changes); a test reads the guide's paragraph on final exits for every exit of SIL-B9; the spec form and budget tests and SIL-AC19 to SIL-AC21 and SIL-AC39 to SIL-AC46 pass.
Weight: light
