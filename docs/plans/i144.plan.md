# Plan: tests of any package get their own home folder and the loop off; `stats forget` drops gone state roots

## 0. Hand-off

- Triage note: `docs/tasks/i144.triage.md`
- Hand-off: `docs/tasks/i144.handoff.md`; its reading list was the start, and no file beyond it was opened except the engine's `tests/test_cli.py` (the `cli` helper, lines 33-46, which the new verb's test uses), `tests/test_sinks.py` (lines 1-60, how a test sets up a home folder and a sink), `tests/test_source_rules.py` (test names only, to see which source rules a new module must keep) and `tempergraph.commands.json` (the commands the repository declares).
- Specs read: `plugins/tempergraph/docs/specs/test-suite.spec.md` (TST-B5, TST-B7, TST-B8, TST-AC6 to TST-AC11), `plugins/tempergraph/docs/specs/central-run-stats.spec.md` (CST-B8, CST-B12, CST-B17 to CST-B21, CST-AC5 to CST-AC10), `plugins/tempergraph/docs/specs/engine-cli.spec.md` (CLI-B8, already lists `stats forget` as not read-only).
- Why this design: the isolation reaches a package's tests with nothing written in the package only through something the engine's install brings along, so the engine ships a pytest plugin (`tempergraph.pytest_plugin`) declared under the `pytest11` entry point; it is a function-scoped autouse fixture that sets `TEMPERGRAPH_HOME` to a folder of its own and `TEMPERGRAPH_LOOP` to `off` with `monkeypatch`, so a test that sets the loop mode itself afterwards keeps its value (TST-B8). The engine's own `tests/conftest.py` fixture stays, because it also clears the caller variables and the suite runs on `PYTHONPATH` where the entry point may not be installed. The verb is the action `forget` of `stats` (hand-off Decisions), written in a new module `observe/forget.py` beside `rows.py` so that `rows.py` (the index lock, `read_index`, `index_roots`, `stats_path`) stays the one place that reads and writes the index. Open questions of the hand-off are taken at their defaults: only the month in which the verb runs (UTC) is cleaned, and TST-B7 and TST-B8 name only the home folder and the loop.
- Test of an isolation that no fixture of the package provides: the engine's test starts the scratch package with `python -m pytest` in the package's folder, in an environment with `TEMPERGRAPH_HOME`, `TEMPERGRAPH_LOOP` and `TEMPERGRAPH_STATE_ROOT` removed, with `PYTHONPATH` at the engine's `src`, and with `HOME` set to a seeded folder so that "the real home folder" of that process is one the test can hash (the suite's own session guard, TST-AC7, still compares the actual `~/.tempergraph` when nothing drives the engine). The plugin is loaded there with `-p tempergraph.pytest_plugin`, because an environment installed before this change has no entry point until it is reinstalled; the entry point is named like its module, so that `-p` finds it already registered where it is installed and `-p no:tempergraph.pytest_plugin` blocks it in the control run.
- Scope cut: none. Whether `doc-refresh-tgraph/tests/test_doc_refresh.py` keeps its own copy of the isolation (hand-off, last reading item) is not part of the task's criteria and the copy stays.
