The five new causes get their tests in one new file named for the capability; the tool-access fix and the `tool_repeat` condition are tested in the files that already pin them.
- Tests that pin what changes: `tests/test_improve.py` lines 29-30 and 177-183 type a pause of kind `tool_access` that the gate never writes, so row 2.2 replaces both with the records of a fixture run. `tests/test_supervision.py` lines 50-53 types a supervision row by hand, reads no cause code, and stays. No test pins `tool_repeat` for repeats that did not fail, and no test constructs `Cause` by position.
