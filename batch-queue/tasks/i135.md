A package states a text part once and includes it in several prompts and judge briefs (GitHub issue #135)

A workflow package keeps its step prompts in `prompts/` and its judge briefs in `judges/`. The engine renders every prompt and brief itself (specs `prompt-rendering` and `workflow-package`), the content digest that makes the workflow version covers each of them (PKG-AC7), and `audit prompts` reads every model-facing file (spec `prompt-audit`, PRA). A package often needs the same rule in many prompts and briefs: what counts as evidence for a grade, which tools a session may use, how a named file must be opened. Today nothing lets it state the rule once, so each file holds its own copy. One package measured on 2026-11-25 holds 8 sentences in 4 to 10 files each, about 6.4 KB of repeated text, and a copy edited alone becomes a second rule that nothing reports.

Wanted: a package declares named text parts once, and a prompt template or a judge brief includes one by name; the engine resolves the includes when it loads the package, with no model, so the session sees the full text. The area is the engine (`plugins/tempergraph`). The engine names no workflow (ADR `the-engine-names-no-workflow`), so the capability is stated for any package and tested with an engine fixture package.

Acceptance criteria:

1. A fixture package that declares one named text part and includes it by name in two prompts and one judge brief loads, with no model call.
2. Each of the two rendered prompts and the rendered brief of that package holds the part's full text.
3. An include that names no declared part is a validation error that names the prompt or the brief and the include.
4. The prompt audit reports an include that names no declared part.
5. The prompt audit reports a declared part that no prompt and no brief includes.
6. A change to a part's text changes the package's content digest, and with it the workflow version.
7. A package that declares no part loads with the same content digest and the same rendered prompts as before this change.
