## Attribution

- A finding of class `infra` (`environmental`, `slow_host`, `auth`, timeouts) or side `host` cannot file by count: `filing.py:105-108` returns before the friction branch. The replay shows `recorded: infra` for `78451d6ca234d294`, and `tests/test_filing.py` covers side `host`.
- The data model has no `request` attribution.
- The gap is a workflow-side fault code whose real cause is the environment or the operator (`check_fail:code`, `retries_spent`, `agent_decided:escalation`, `idle_burn`). The only gate is this run's `attributed` flag, at any confidence, 0.0 included.

## Findings

1. The attribution gate is one draw of an unstable flag, with no minimum confidence. `filing.py:115-119`. Evidence: `retry_burst` files on (true, 0.40) after (false, 0.45); `agent_decided:escalation` at phase files on one true after one false. The judge brief (`child.py:44-56`) does not tell the judge that "true" at 0.35 now files. Fix: require a majority of the recorded `answers[]` for the fingerprint to be attributed (SIL-B36 now records them), or a low second floor such as 0.5 for filing by count.
2. No cap on "seen again" comments. `filing.py:413-415`. A cause present in 7 of 7 runs gets a comment with the environment and a 40-line log excerpt at every exit. Fix: at most one comment per issue per day, or a comment only when the run count crosses a step.
3. A loop issue closed as `duplicate` is filed again at the next exit. `filing.py:404-411` mutes only `not_planned` and links only `completed`. It predates the merge and matters now, because three would-be issues repeat issues a person filed. Fix: treat `duplicate` like `not_planned`. Until then, close as "not planned" to mute for 30 days (`mute.days`).
4. Reason `below_floor` covers three cases. `filing.py:116,122`: not attributed (even at 0.9), below the count, and below the floor. A below-count decision carries no `counts`, and a `filed` row carries no reason. Fix: reason `not_attributed`, counts on every friction decision, the reason on `issue_filed`.
5. Mixed engines on one ticket queue. `detach.start` uses `sys.executable`, and `drain` claims every waiting ticket. Runs i150 and i153 are still on `0.2.0-7f7c4cf67b49`; a child started by i170's exit would decide their tickets by the new rule, and the reverse. Any hold must be on the ticket (dry run or autonomy), not on the engine.
6. No lock around "read the open list, then create". `filing.py:389-420`. Two children filing the same cause within seconds would open two issues. It predates the merge and the window is small, and it is more likely now that most exits file.
7. Requests can be reached inside one thread. `filing.py:88-90`. Thread i123 carries two digests, so `tool_repeat` at phase shows 5 runs and 7 requests. With both minima at 3, a request edited within one run can stand in for a missing distinct request. Fix: count a request once per thread.
8. `tests/test_loop_open_questions.py` asserts spec prose. When the owner answers either question the test fails. Either accept it as the proof of criteria 8 and 9, or delete it with the answer.
9. Placement of criterion 9. The question is in `review-repeats.spec.md`; the task says "kept in the spec" in the context of `self-improvement`. Acceptable, since SRV-B28 owns the behaviour.

## Recommendation

- No parameter can hold filing: `improve/params.py` is constants and has no set verb. The hold is per ticket.
  - New runs: `tempergraph run <workflow> --dry-run ...`. The judge and the reviews still run, `answers[]` is logged, and `loop.jsonl` gets `would_file` rows with titles, which is the best way to watch the rule for a day.
  - Resumes (`resume` has no `--dry-run`): `export TEMPERGRAPH_AUTONOMY=record` in the launch shell before `tempergraph resume ...`. Results are recorded as `autonomy_record` and nothing files.
- Run i170 has neither. If it reaches its final exit without a pause it files for real, most likely `tool_repeat`, `idle_burn` and `context_bloat`. If it pauses, resume it with `TEMPERGRAPH_AUTONOMY=record`.
- If something does file: close noise as "not planned", not "duplicate".
- Before lifting the hold: fix findings 1 and 2. Finding 3 is cheap and worth doing with them.

## Appendix: the probe script

Read-only: it blocks `subprocess`, files to a `MemoryCodeHost`, and writes only its outbox under the folder given as its argument. That folder must hold `loop_issues.json`, the output of `gh issue list --repo dbr0vskyi/tempergraph --label tempergraph-loop --state all --limit 100 --json number,title,state,closedAt,body,labels,createdAt`. Run with the main checkout's environment: `TMPDIR=/home/dbr0vskyi/tg-runs/tmp .venv/bin/python probe.py <folder>`.

```python
import sys, json, glob, os, re, tempfile, collections
from pathlib import Path
sys.path.insert(0, "/home/dbr0vskyi/projects/tempergraph/plugins/tempergraph/engine/src")
from tempergraph.improve import filing, child
from tempergraph.improve.codehost import MemoryCodeHost
from tempergraph.improve.record import read_findings
import subprocess
# hard guard: no subprocess may start (no gh, no network)
def _no(*a, **k): raise RuntimeError("subprocess blocked in probe")
subprocess.Popen = _no; subprocess.run = _no
ROOT = Path("/home/dbr0vskyi/projects/tempergraph/.tempergraph"); WF = "temperspec"
S = Path(sys.argv[1])
real = json.load(open(S / "loop_issues.json"))
reasons = {115: "duplicate", 116: "duplicate"}
def host():
    h = MemoryCodeHost()
    for i in sorted(real, key=lambda x: x["number"]):
        h.issues.append({"repo": "dbr0vskyi/tempergraph", "number": i["number"], "title": i["title"], "body": i["body"],
                         "labels": [l["name"] for l in i["labels"]], "state": i["state"].lower(),
                         "state_reason": reasons.get(i["number"], ""), "closed_at": i.get("closedAt") or "",
                         "url": f"real#{i['number']}"})
    return h
# real judge answers from raw logs
answers = {}  # ticket -> {fp: {...}}
for d in glob.glob(str(ROOT / "runs" / WF / "*/loop/sessions/friction-*")):
    tid = d.rsplit("friction-", 1)[1]; text = ""
    for ln in open(d + "/raw.jsonl"):
        try: r = json.loads(ln)
        except ValueError: continue
        if r.get("type") == "result" or "result" in r and isinstance(r.get("result"), str):
            text = r.get("result") or text
    answers[tid] = child.parse(text)
allans = [a for t in answers.values() for a in t.values()]
print("judge answers read from raw logs:", len(allans), "attributed false:", sum(1 for a in allans if not a["attributed"]),
      "max conf:", max(a["confidence"] for a in allans), "tickets:", {k: len(v) for k, v in answers.items()})
tickets = []
for p in sorted(glob.glob(str(ROOT / "runs" / WF / "*/loop.jsonl"))):
    task = p.split("/")[-2]
    for ln in open(p):
        r = json.loads(ln)
        if r.get("kind") == "loop_started":
            tickets.append((r["ts"], task, r["ticket"], r["fingerprints"]))
tickets.sort()
names = {}
for task in os.listdir(ROOT / "runs" / WF):
    for f in read_findings(ROOT, WF, task):
        names[f["fingerprint"]] = (f.get("cause"), f.get("unit"), f.get("class"), f.get("side"), f.get("lens"))
out = Path(tempfile.mkdtemp(dir=S))
def replay(label, assume=None, tix=tickets):
    print(f"\n===== {label}")
    h = host(); n0 = len(h.issues); filed = collections.Counter()
    for ts, task, tid, fps in tix:
        thread = f"{WF}/{task}"
        mine = child._latest(read_findings(ROOT, WF, task), set(fps))
        hist = child._history(ROOT, WF, thread)   # NOTE: today's full history, an upper bound for older tickets
        cands = []
        for f in mine:
            if f.get("lens") in ("review", "outcome"): continue
            j = (answers.get(tid) or {}).get(f["fingerprint"]) if assume is None else assume
            cands.append(filing.Candidate(finding=f, lens="friction", confidence=j["confidence"] if j else None,
                         attributed=bool(j and j["attributed"]), request_digest=f.get("request_digest"), records=[]))
        ds = [filing.decide(c, hist, "dbr0vskyi/tempergraph") for c in cands]
        res = filing.file(ds, h, filing.Outbox(path=out / "outbox.jsonl"))
        ops = collections.Counter(r["op"] + (":" + r.get("reason", "") if r["op"] == "recorded" else "") for r in res)
        print(f"-- ticket {tid} {task} {ts[:16]} findings {len(cands)} -> {dict(ops)}")
        for d in ds:
            if d.action == "file":
                f = d.candidate.finding
                print(f"     FILE {f['fingerprint']} {f['cause']} @ {f.get('unit') or '-'} conf={d.candidate.confidence} {d.reason} {d.counts}")
        for r in res:
            if r["op"] in ("filed", "commented", "muted"): filed[r["op"]] += 1; print("     ->", r["op"], r.get("url"), r["fingerprint"])
    print("TOTAL", dict(filed), "new issues:", [(i["number"], i["title"]) for i in h.issues[n0:]])
    return h
replay("A: recorded tickets in order, REAL judge answers (new rule, today's history)")
replay("B: recorded tickets in order, every finding assumed attributed at 0.5", {"attributed": True, "confidence": 0.5})
# C: the next exits: each thread's final exit carrying ALL its friction fingerprints (what #170 would send), assumed attributed 0.5
allfp = []
for task in sorted(os.listdir(ROOT / "runs" / WF)):
    fs = read_findings(ROOT, WF, task)
    if fs: allfp.append(("next", task, "hyp-" + task, sorted({f["fingerprint"] for f in fs})))
replay("C: one final exit per thread with every fingerprint of the thread, assumed attributed at 0.5", {"attributed": True, "confidence": 0.5}, allfp)
# cluster table
rows = collections.defaultdict(lambda: [set(), set(), set()])
for task in os.listdir(ROOT / "runs" / WF):
    for f in read_findings(ROOT, WF, task):
        if f.get("lens") in ("review", "outcome") or f.get("class") != "fault": continue
        r = rows[f["fingerprint"]]; r[0].add(f["thread"]); r[2].add(f.get("machine"))
        if f.get("request_digest"): r[1].add(f["request_digest"])
print("\n===== friction fault clusters (runs, requests, machines)")
for fp, (a, b, c) in sorted(rows.items(), key=lambda x: -len(x[1][0])):
    js = [(round(t[fp]["confidence"], 2), t[fp]["attributed"]) for t in answers.values() if fp in t]
    print(fp, names[fp][0], "@", names[fp][1] or "-", "runs", len(a), "reqs", len(b), "machines", len(c), "MEETS" if len(a) >= 3 and len(b) >= 3 else "", "judge:", js)
```
