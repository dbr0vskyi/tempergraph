## Exits, double judging, cost, the pattern rule

- Which exits start a loop child. SIL-B9 makes every exit 0, 4 or 5 final, so `stopped_by_request`, `attempt_cap`, `budget` and `cost_cap` are final; a pause never makes a ticket. The three issues #198 to #200, filed at the stop exit of i170, were filed as the spec says, and this change does not alter the trigger. It widens what such an exit carries: every exit 4 or 5 now brings the thread's unjudged pause findings (before, only a person's stop). An operator's `stop` that moves a run to a new engine is a final exit that judges and files, though the thread goes on.
- Double judging. A pause finding is handed once: `unjudged_pause_findings` leaves out a fingerprint that a later `loop_started` names. A fingerprint in both a paused segment and the last one is judged once per ticket. The "seen again" comment per exit and cause (finding 2 of the i171 review) now has more causes per exit.
- Cost. One judge session per ticket, not per finding. The 12 real judge sessions of the night cost 0.009 to 0.029 USD each. The prompt of i123b's exit 0 grows by about 1,000 input tokens and 16 answers: about 0.02 to 0.03 USD. At an exit that is not a person's stop the pause fingerprints go to `pause_fingerprints` and plan no session review (SIL-AC45).
- The pattern rule (#171). Nothing is counted twice: `_pattern` counts distinct threads and request digests, and the pause findings were already in the history other threads read. What changes is how many candidates reach `decide` with a judge's answer.

## What the loop can now explain to a person, and what it cannot see

It can now explain:

- That a pause happened at a unit, for which reason of the engine, how it was answered, by which kind of caller, and with or without feedback, for the unit that paused.
- A judge that reversed on a retry with nothing changed (i123b `outcome`), in effect; it has no cause code.

It still cannot see:

- A plan row a session cannot do (i153 p4, i148 p4): `blocked` is class `designed` and never judged. Missing signal: the kind of block (a capability or command the session lacks).
- A false check finding from an engine defect (`ts-code-ruleread`, #191): the finding is `check_fail:<unit>`, side `workflow`. Missing: the failing check's id in the finding, and an enum for why the operator overrode (engine defect, judge error, environment, plan, request), which gives the judge the cause with no feedback text.

- Why the operator proceeded: only "feedback given". The text stays local by design; the enum above is the missing piece.

## Appendix: the probe script

Read-only against the real state root: it blocks `subprocess`, copies one thread's `run.jsonl`, `findings.json` and the ledger into a scratch folder with `loop.jsonl` cut to just before the exit, and calls the engine's functions on the copy. Run with the main checkout's environment: `TMPDIR=/var/tmp/tg-runs .venv/bin/python probe.py <task>... -v`. The filing replay used the same copy, with `filing.decide` and `filing.file` against a `MemoryCodeHost` seeded as the i171 review's appendix does, and the judge answers read from `loop/sessions/friction-*/raw.jsonl`.

```python
import sys, json, shutil
from datetime import datetime, timedelta
from pathlib import Path
sys.path.insert(0, "/home/dbr0vskyi/projects/tempergraph/plugins/tempergraph/engine/src")
import subprocess
def _no(*a, **k): raise RuntimeError("subprocess blocked")
subprocess.Popen = _no; subprocess.run = _no
from tempergraph.improve import child, record, pause_facts
from tempergraph.improve.record import read_findings
REAL = Path("/home/dbr0vskyi/projects/tempergraph/.tempergraph"); WF = "temperspec"
S = Path("/var/tmp/tg-runs/rev170/root"); VERB = "-v" in sys.argv
def jl(p):
    out = []
    for ln in open(p):
        try: out.append(json.loads(ln))
        except ValueError: pass
    return out
def setup(task, cut):
    """A copy of the thread as it stood just before the loop child of the exit at `cut` started."""
    d = S/"runs"/WF/task; shutil.rmtree(S, ignore_errors=True); d.mkdir(parents=True)
    src = REAL/"runs"/WF/task
    recs = [r for r in jl(src/"run.jsonl") if str(r.get("ts")) <= cut[1]]
    (d/"run.jsonl").write_text("".join(json.dumps(r)+"\n" for r in recs))
    loops = [r for r in jl(src/"loop.jsonl") if str(r.get("ts")) < cut[0]] if (src/"loop.jsonl").exists() else []
    (d/"loop.jsonl").write_text("".join(json.dumps(r)+"\n" for r in loops))
    doc = json.loads((src/"findings.json").read_text())
    doc["findings"] = [f for f in doc["findings"] if str(f.get("at")) <= cut[2]]
    (d/"findings.json").write_text(json.dumps(doc))
    (S/"ledger.jsonl").write_text("".join(json.dumps(r)+"\n" for r in jl(REAL/"ledger.jsonl")))
for task in [a for a in sys.argv[1:] if not a.startswith("-")]:
    recs = jl(REAL/"runs"/WF/task/"run.jsonl")
    finals = [(i, r) for i, r in enumerate(recs) if r.get("kind") == "run_exit" and r.get("exit_code") in (0, 4, 5)]
    for n, (i, ex) in enumerate(finals):
        fr = next(r for r in recs[i:] if r.get("kind") == "finding_recorded")
        t = datetime.fromisoformat(fr["ts"].replace("Z", "+00:00"))
        setup(task, (ex["ts"], fr["ts"], (t + timedelta(seconds=3)).isoformat()))
        thread = f"{WF}/{task}"
        earlier = record.unjudged_pause_findings(S, WF, task, thread)
        pfp = {x["fingerprint"] for x in earlier if x.get("lens") not in ("outcome", "review")}
        last = set(fr.get("fingerprints") or [])
        mine = child._latest(read_findings(S, WF, task), last | pfp)
        faults = [f for f in mine if f.get("class") == "fault" and f.get("lens") not in ("outcome", "review")]
        ans = pause_facts.of(S, WF, task, faults)
        pr = child.prompt(faults, child._records(S, WF, task), ans)
        old = child.prompt([f for f in faults if f["fingerprint"] in last], child._records(S, WF, task))
        print(f"\n===== {task} exit#{n+1} code={ex['exit_code']} reason={ex.get('reason')} | last-seg fps {len(last)}"
              f" | pause fps {len(pfp)} (new {len(pfp-last)}) | faults judged {len(faults)}"
              f" | prompt chars {len(pr)} (was {len(old)}) | facts lines {len(ans)}")
        if VERB:
            for f in sorted(faults, key=lambda f: (str(f.get("at")), f["cause"])):
                a = ans.get(f["fingerprint"])
                print(f"  {'last' if f['fingerprint'] in last else 'PAUSE'} seg_exit={f.get('segment_exit')} "
                      f"{f['fingerprint']} {f['cause']} @ {f.get('unit') or '-'} at={str(f.get('at'))[11:19]}"
                      + (f"\n      -> reason {a['reason']}; decision {a['decision']}; caller {a['caller']}; "
                         f"feedback {a['feedback']}; workspace {a['workspace']}; next gate {a['next_gate']}" if a else ""))
            print("  not judged:", [(f["cause"], f.get("unit"), f["class"], f.get("lens")) for f in mine if f not in faults])
shutil.rmtree(S, ignore_errors=True)
```
