temperspec: score setup's extraction on a fixture repository with planted rules (GitHub issue #130)

The setup step of temperspec writes an overview spec and one spec per component from existing code, by `rules/extraction.rule.md`: a rule becomes a behaviour only on the basis `tested` or `read`, the setup note lists each behaviour under Evidence (`ts-set-evidence`), and a suspected bug that no test pins stays out of the specs and goes under Anomalies of the setup note. None of this has been measured: temperspec has had no real setup run (research `spec-extraction-from-existing-code` conclusion 9). The package's `evals/` holds calibration cases for the setup judge (`evals/calibration/setup/`, for `ts-set-true` and `ts-set-cover`) and no repository with a known answer. Wanted: a small fixture repository with a planted list of business rules, invariants and one deliberate bug, so that the output of a stand-in or live setup run can be scored for missed rules, invented rules and where the bug lands. The area is temperspec (`plugins/temperspec-tgraph`).

The issue also asks for one recorded live setup run with its score. A live run is made by the operator after the merge and is not part of this task.

Acceptance criteria:

1. A fixture repository under `plugins/temperspec-tgraph/evals/` holds planted business rules, planted invariants and one deliberate bug, and a file beside it lists each of them.
2. A scorer compares the specs and the setup note of a setup run on the fixture with the planted list and reports each planted rule and invariant that no spec holds.
3. The scorer reports each behaviour of the specs that the planted list does not hold.
4. The scorer reports whether the planted bug is listed under Anomalies of the setup note and is in no spec.
5. A test in the package's suite scores the output of a stand-in setup run that misses one planted rule, adds one rule of its own and writes the bug as a behaviour, and the scorer reports each of the three.
6. `evals/calibration/setup/` holds a calibration case for the setup judge that is built from the fixture.
